# Junior Skepticism Gap Calculator

A single-page app in one file (`index.html`) with no dependencies. It's the companion tool for an edition of the LinkedIn newsletter **AI in Finance, Done Right**: **"Why Deloitte's Best AI Audit Feature Isn't Faster Extraction—It's the 'Tutor' Built Into the Workflow"**.

## Features
- **Tab 1, Apprenticeship gap:** Enter your junior headcount, first-pass hours per junior, the share AI now does, and how much freed time goes back into coaching. See the practice hours lost, coaching put back, the net gap per junior (in hours and weeks) and for the team, with a band that says how urgent a training redesign is.
- **Tab 2, Workflow readiness:** Six gates from the article: coaching in the review step, "why" checklists, source grounding, mandatory sign-off, agents sharing context, and reduced app sprawl. You get a readiness dial, the biggest gaps and a training redesign memo you can copy.

Hours are a rough proxy for learning by doing, not a skill measure. The demo figures are made up. Everything runs in the browser and nothing is uploaded.
